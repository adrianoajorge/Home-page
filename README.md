## Como funciona

`index.html` é a página completa (HTML, CSS e JavaScript em um único arquivo).
As fotos (`.jpg`), vídeos (`.mp4`) e o mapa (`map-location.png`) ficam na raiz do
repositório, referenciados por caminho relativo.

Para publicar uma alteração: editar o arquivo, fazer commit no branch `main` e o
GitHub Pages atualiza a página automaticamente em 1–2 minutos.
